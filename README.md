## Development

Clone the repository:

```bash
git clone https://github.com/ayushrout12/ayushrout.xyz.git
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

---

## Deployment

Hosted on **Vercel**.
